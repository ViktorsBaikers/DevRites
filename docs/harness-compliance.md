# Harness adapter compliance

DevRites drives more than one agent runtime from a single `devrites-engine`
binary, but the runtimes do not expose identical enforcement surfaces. This page
states — per surface — whether each supported harness enforces it natively,
through an adapter, or only by instruction the model may ignore. It is the honest
answer to "does DevRites work the same on Codex as on Claude Code?"

The table below is **generated**. The single source of truth is the frozen matrix
in `engine/internal/harness/compliance.go`; regenerate this block with:

```sh
devrites-engine harness-matrix          # print the block
```

CI runs `devrites-engine harness-matrix --check docs/harness-compliance.md`, so
the table and the code can never silently drift apart.

| Surface | Claude Code | Codex | Notes |
| --- | --- | --- | --- |
| SessionStart orientation | Native | Native | Both wire the orient hook; identical additionalContext envelope. |
| PreToolUse allow / deny (allow, a1-guard, reviewer-readonly, wright-scope) | Native | Native | Codex wires the same PreToolUse guards with agent-type gating. |
| PostToolUse sentinel (redwatch) | Native | Native | Fail-on-red sentinel wired on both. |
| Stop gate | Native | Native | Both honour the {decision:block} convention. |
| SubagentStart discipline injection | Native | Native | subagent-orient wired on both. |
| Skill invocation | Native | Adapter-backed | Claude: native /rite. Codex: $rite over the mirrored .agents/skills tree. |
| Reviewer subagent dispatch | Native | Instruction-backed | Codex under-fires embedded spawns (openai/codex#23496); falls back to .codex/agents + a labelled inline pass. |
| Standards step-0 load | Native | Instruction-backed | Claude: skill Reads core.md. Codex: an AGENTS.md directive to read it. |
| Project activation | Native | Conditional | Codex silently skips every .codex/ layer in an untrusted project until it is trusted. |

Tiers: **Native** (harness enforces it directly) · **Adapter-backed** (supported through a translation shim) · **Instruction-backed** (no runtime surface — rides on a directive the model may under-fire) · **Conditional** (native but gated on an operator precondition).
