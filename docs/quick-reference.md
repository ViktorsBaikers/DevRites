# DevRites quick reference

DevRites is installed and updated through `npx devrites ...`. Claude and Codex files are project-local artifacts generated by that npm flow; there is no Claude/Codex plugin distribution path.

## What do I run?

| Situation | Command | Notes |
| --- | --- | --- |
| Start a feature | `/rite-spec` / `$rite-spec` | Creates/refreshes the feature workspace and acceptance criteria. |
| Shape a risky idea before spec | `/rite-frame` / `$rite-frame` or `/rite-temper` / `$rite-temper` | Use when scope or strategy is unclear. |
| Turn spec into slices | `/rite-define` / `$rite-define` | Produces plan/tasks and AC traceability. |
| Validate plan before code | `/rite-vet` / `$rite-vet` | Reviewer pass before writing production code. |
| Build the next slice | `/rite-build` / `$rite-build` | One verified production slice at a time by default. |
| Explore safe parallelism | `devrites-engine lanes plan [slug]` | Advisory only; does not authorize parallel production writes. |
| Prove behavior | `/rite-prove` / `$rite-prove` | Writes evidence/proof. |
| Polish code/UI | `/rite-polish` / `$rite-polish` | Uses code/UI craft references. |
| Review adversarially | `/rite-review` / `$rite-review` | Produces review findings/no-findings justifications. |
| Decide GO/NO-GO | `/rite-seal` / `$rite-seal` | Decision only, no irreversible git action. |
| Ship after explicit GO | `/rite-ship` / `$rite-ship` | Requires typed confirmation before commit/push/tag. |
| Resume / inspect state | `/rite-status` / `$rite-status`, or `devrites-engine snapshot [slug]` | Snapshot emits `devrites.workspace.v1` JSON. |
| Diagnose install/tool readiness | `/rite-doctor` / `$rite-doctor`, or `devrites-engine doctor` | Version triangle, active-workspace dashboard, optional capability inventory. |
| Learn from shipped work | `/rite-learn` / `$rite-learn` | Human-gated learning ledger with confidence/evidence. |

## Hard boundaries

- Keep install/update/uninstall npm/npx-managed.
- Generated `.claude`, `.agents`, `.codex`, and `AGENTS.md` files are project-local host artifacts, not plugin-store packages.
- Do not bypass seal/ship split or typed `GO`.
- Use `devrites-engine snapshot` / doctor output for dashboards before building GUI surfaces.
