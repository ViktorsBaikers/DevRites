Command map

Every shipped skill and agent: what triggers it, and what it reads and writes. Each phase has a menu form (/rite <verb>) and a direct shortcut (/rite-<verb>); both run the same skill.

Public commands

CommandPhaseWhat it does
/ritemenuCompact menu and suggested next command. Pure router.
/rite-specspecStart here. Deep investigation, then writes spec.md and creates the workspace.
/rite-defineplanTurns the approved spec into a plan and vertical task slices.
/rite-planplanDecompose, reslice, repair, re-order, split, or unblock an active plan.
/rite-buildbuildImplement exactly one vertical slice, then stop with evidence.
/rite-proveproveTests, build, runtime, and browser proof of the finished feature.
/rite-polishpolishBehavior-preserving cleanup, then UI polish against the design system.
/rite-reviewreviewFeature-scoped multi-axis review with parallel reviewers.
/rite-sealsealFinal GO / NO-GO. Walks acceptance, fans out reviewers, demands type-GO.
/rite-statusstatusActive feature: phase, run mode, next action, evidence, open gates, risks.
/rite-resolveresumeAnswer, drop, or batch-resolve open gates; resumes the build.
/rite-zoom-oututilityOne-pass structural map of an unfamiliar area, in project vocabulary.
/rite-prototypeutilityThrowaway code answering one design question. Logic harness or UI variations.
/rite-handoffutilityCompacts the chat into a handoff doc; syncs context into workspace files.
/rite-pressure-testutilityPressure-test a rough idea: diverge into options, converge on one.

Internal skills

Model-invoked specialists, hidden from the menu. They fire automatically when a phase needs them.

SkillTriggered byRole
devrites-interviewunderspecified askOne-question-at-a-time protocol with best-guess and confidence stop.
devrites-source-drivenuncertain framework factConsult docs or source, record the citation in evidence.
devrites-doubtnon-trivial decisionAdversarial: claim, extract, doubt, reconcile, stop.
devrites-frontend-craftUI in build or polishRegister detection, shape-before-code, states, anti-slop guardrails.
devrites-browser-proofUI in prove or polishBrowser proof ladder and evidence schema.
devrites-debug-recoveryfailing tests or buildSix-phase: loop, reproduce, hypothesize, instrument, fix, clean up.
devrites-api-interfacecross-boundary sliceStable API and contract design across a front-end / back-end split.
devrites-auditpolish, or risk in scopeSimplify, security, and perf audits, each dispatching a reviewer.

Review agents

Fresh-context reviewers spawned by /rite-review and /rite-seal. None is the agent that wrote the code, so none inherits its blind spots.

AgentChecks
devrites-spec-reviewerDoes the diff implement the spec? Missing, partial, or wrong criteria; scope creep.
devrites-code-reviewerCorrectness, readability, architecture, maintainability.
devrites-test-analystDo the tests actually prove the acceptance criteria?
devrites-frontend-reviewerUX, accessibility, responsive behavior, design system, anti-AI-slop.
devrites-security-auditorOWASP Top 10, trust boundaries, secrets, dependencies.
devrites-performance-reviewerN+1 queries, hot paths, payload size.
devrites-doubt-reviewerAdversarial check of a single claim or decision.
devrites-simplifier-reviewerIndependent simplification judgment under Chesterton's Fence.
Naming The devrites- prefix is a namespace for collision avoidance against bundled Claude Code skills. It does not mean "internal" — visibility is set by the user-invocable flag in each skill.
