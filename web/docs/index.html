DevRites / docs / overview

Documentation

DevRites is a project-local pack of Claude Code skills that runs a disciplined senior-engineer workflow: spec, plan, build one verified slice, prove with evidence, polish, review, seal. Every phase reads the last one's files and writes its own, so state lives on disk rather than in a chat window.

Quick start

Install into a project, then start a feature. /rite-spec investigates the codebase, writes the spec, and creates the workspace for you.

# install into the current project (never writes to ~/.claude) curl -fsSL https://raw.githubusercontent.com/ViktorsBaikers/DevRites/main/install.sh | bash # then, inside Claude Code: /rite-spec "add refresh-token rotation"

From there each phase has a menu form (/rite <verb>) and a direct shortcut (/rite-<verb>). They run the same skill. Run /rite for the menu, or /rite-status to see where the active feature stands.

The workspace

Every feature gets its own directory under .devrites/work/<slug>/. When the context window fills and you /clear, the next agent reads these files and resumes exactly where the last one stopped.

.devrites/ ACTIVE # which feature is active AFK # presence = AFK mode (YAML body: max_slices / notify) work/<slug>/ spec.md plan.md tasks.md state.md evidence.md decisions.md assumptions.md drift.md questions.md references/ browser-evidence.md touched-files.md polish-report.md review.md seal.md handoff.md
Why on disk spec.md holds the contract. decisions.md and assumptions.md hold the reasoning. evidence.md holds the proof. drift.md records where the plan was wrong and why. None of it depends on a chat summary you can lose.
