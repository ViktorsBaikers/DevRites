# Generated DevRites Host Artifacts

This directory is generated by `scripts/build-host-artifacts.sh`.

- `claude/` contains Claude Code-native skills, agents, and settings.
- `codex/` contains Codex-native skill mirrors, custom-agent TOML, hook
  blocks, and AGENTS bridge content.

Do not edit these files by hand. Edit `pack/.claude/` or
`scripts/codex-generate.sh`, then rebuild.
